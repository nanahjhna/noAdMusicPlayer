【1. 프로젝트 개요】
--------------------------------------------------------------------------------
- 프로젝트명   : noad_music_player (앱 표시명: noAdMusicPlayer / No Ad Music)
- 버전         : 1.0.0+16
- 플랫폼       : Android, iOS, Web, Windows, Linux, macOS (Flutter 멀티플랫폼)
- SDK          : Dart >=3.1.0 <4.0.0
- 앱 성격      : 기기에 저장된 로컬 음원을 스캔하여 광고 없이 재생하는
                로컬 음악 플레이어 (Spotify풍 다크 테마, 초록색(#1DB954) 포인트)
- 주요 기능 요약:
  1) 로컬 음원 스캔 및 목록 표시 (mp3/m4a/flac/wav/ogg)
  2) 곡 재생/일시정지/이전/다음, 셔플, 반복(전체/한 곡)
  3) 검색 (곡명/아티스트)
  4) 플레이리스트 생성/추가/삭제 (SharedPreferences 기반)
  5) 곡 이름 변경 / 곡 파일 삭제 / 파일 정보 보기
  6) 미니 플레이어 및 전체 화면 플레이어 (앨범 아트 포함)
  7) 백그라운드 재생 (just_audio_background, Android Foreground Service)
  8) 다국어 지원 (한국어/English/日本語)
  9) 마지막 재생 상태 저장 및 복원 / 재생 모드(셔플·반복) 저장
  10) Supabase 연동 골격 (현재 미완성 - placeholder 키 사용)

【4. 아키텍처 및 데이터 흐름】
--------------------------------------------------------------------------------
main()
 ├─ JustAudioBackground.init()      # 백그라운드 오디오 채널 초기화
 ├─ Supabase.initialize()           # ⚠️ placeholder URL/Key 사용 중
 └─ runApp(MyApp)                   # 다크 테마 MaterialApp, 3개 로케일 지원
      └─ SplashScreen               # 저장된 언어 로드 → 2초 대기 → MainHolder 이동

MainHolder (하단 탭: 음악 / 플레이리스트 / 설정)
 ├─ 음악 권한 확인 (on_audio_query) → 음원 스캔 (30초 미만 곡 제외)
 ├─ IndexedStack으로 3개 탭 페이지 유지
 ├─ sequenceStateStream 감시 → 재생 시 미니 플레이어 노출
 └─ PopScope로 뒤로가기 시 앱 종료 확인 다이얼로그

[재생 흐름]
사용자 탭 → HomeScreen._playMusic(index)
 → 전체 목록에서 원곡 인덱스 탐색 (검색/셔플 대비)
 → AudioManager.playMusic() → ConcatenatingAudioSource 생성
 → player.setAudioSource(playlist, initialIndex) → player.play()

[상태 저장]
currentIndexStream 감시 → StorageService.saveLastStatus()
  : 마지막 곡 index/position/songId 저장
  : 셔플/반복 모드 → savePlayMode()
  : 플레이리스트는 JSON으로 직렬화하여 저장
